# Publishing through his Postiz

Read when you touch `src/lib/postiz/`, the Publishing dialog, the Export dialog's Publish mode, or the `publish.*` commands.

## The decision and where it came from (2026-11-10, lab 1)

**Decision.** The maintainer asked for Atelier's Postiz work (Recap's Export › Publish, labs 12–15 in `CostardRouge/atelier`, `docs/memory/recap.md`) in Sketchbook: a connection to his own Postiz (address + API key) and publishing or scheduling from the Export dialog. Lab 1 (https://claude.ai/artifact/TTifpoULxuwogN14e2UbGh) drew it; his answer: «prends tes recommandations, vas-y» — every recommendation of its §10: schedule in one gesture for Schedule and Draft, a review screen before Publish now (the one irreversible send); ONE variant per post, sent to several accounts; every Instagram, TikTok and YouTube account of his Postiz with each network's required settings; a rhythm of Sketchbook's own, defaulting to Atelier's; the long default caption; the gallery's Planned strip later (his call, not built). **How to apply**: change a choice only on his word; the lab's §8 lists the UX law each one serves.

## The key never reaches the server (2026-11-10)

**Decision.** The API key lives in this browser's `localStorage` (`sketchbook.postiz.v1`, `store.ts`) and the TAB calls Postiz directly (`client.ts`), exactly as Atelier does — even though Sketchbook has a server. **Why**: every route here is public and unauthenticated (`security.md`); a server route holding the key would be an open relay to his Instagram. An agent publishes through the tab too (the studio relay, `agent-commands.md`). **How to apply**: never add an API route that talks to Postiz or stores the key; a file goes from the tab's memory to Postiz, never through MinIO. His Postiz must list this site's origin in its CORS (`https://p5.steeve.website`, `http://localhost:3000` for dev) — Atelier lost a day to a bare network error that was only that.

## `src/lib/postiz/` is Atelier's client, ported, plus several accounts (2026-11-10)

`client.ts` and `rhythm.ts` are copies of Atelier's `src/shared/sources/postiz/` with their specs (Vitest → Jest); every limit there was measured on his instance (Cloudflare's 413 without CORS above 100 MB → `uploadProblem` at 95 MB; Postiz's 10 MB image cap; Instagram's 10-item carousel; captions kept as HTML → `postizText`; 90 posts an hour; no retry nor move in the public API). **A fix to either copy belongs in the other.** What differs: `postBody` takes several `channels` — one `POST /posts` with an entry per account, the same caption and uploaded files on each (Postiz's own model) — and `channelSettings` fills each network's REQUIRED settings, read from his Postiz's `integrationSchema` on 2026-11-10: Instagram `post_type` / trial / collaborators (Atelier's); TikTok `privacy_level`, `duet`/`stitch` false, `comment` true, `autoAddMusic: "no"`, both brand toggles false, `content_posting_method: "DIRECT_POST"` (UPLOAD would only drop it in the app's inbox), `video_made_with_ai` on videos only; YouTube `title` (2–100) and `type` (public/unlisted/private). Any other network is listed and refused (`providerOf` → `other`). Caption limits per network (`CAPTION_LIMIT`: 2 200 / 2 000 / 5 000) — the shortest of the ticked accounts wins (`captionLimit`). His Postiz had two Instagram accounts on 2026-11-10, so `initialDefaults` ticks none until he picks.

**Pure modules**, each with its spec: `postShape.ts` says what a VARIANT can be posted as before it renders (one mp4 → Reel/Post/Story, several files → Carousel, webm/gif or more than 10 files → nothing, with the reason); `caption.ts` fills the template (`{title} {description} {tags} {engine} {seconds} {link} {sketch}`; `sketchTitle` drops the version: `iridescent-v7-peaks-shell` → `Iridescent · Peaks shell`); `publishStore.ts` keeps a sketch's post (variant, kind, accounts, caption, approval, network settings, what it sent) per sketch beside the variant list — never in the document, for the variant store's reason — with the WHEN in memory only (a stored date goes stale); new words take the approval back (`patchedDraft`). `send.ts` is the ONE send path (`sendProblem` before a byte leaves, `postableFile` turns a PNG into the JPEG Instagram requires — drawn on white, the person's download stays PNG — uploads one at a time, one post request).
