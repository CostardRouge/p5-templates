# Security

Read before adding or changing an API route, a server action, anything that turns request data into a path, an S3 key or an outbound request, or anything in `.env.example`.

## There is no authentication, so every route is a public endpoint

2026-10-02 — No proxy/middleware, no session, no API key: every handler under `src/app/api/` and every server action in `src/app/actions/` is callable by anyone who can reach the host, and the deployed host is on the public internet (`p5.steeve.website`, framed by steevepommier.com). The `NEXT_PUBLIC_*` feature flags only hide UI — no route checks `BACKEND_RECORDING` before acting. `/api/dev/*`, `/api/thumbnails/generate` and `/api/previews/generate` refuse in production (`NODE_ENV === "production"`) and are only reachable under `next dev`, which listens on the LAN. Adding auth is the maintainer's decision (TODO: N8n API key, multi-user). **How to apply**: until then, write every handler as if the caller is hostile — validate each parameter at the boundary, and never let one become a filesystem path, an S3 key prefix, a URL the server fetches, or a shell argument without a check.

## `.env.example` holds names and safe defaults, never a key

2026-10-02 — The template shipped a real VAPID private key, and the chain made it everyone's: `setup.sh` copies the template to `.env`, and `scripts/generate-vapid-keys.mjs` skipped any `.env` whose key lines merely existed. The template now has both lines empty, the generator treats an empty value as missing (fills the line in place, no duplicate), and `setup.sh` runs it, so a fresh install still gets working notifications, with its own pair. The infra passwords in the template (`minio123`, the Postgres one) are local-dev defaults the compose file repeats, not secrets of a deployment. **How to apply**: a value that signs, decrypts or authenticates against something outside the developer's machine never goes into the template, not even as an example; generate it in setup instead.

## A job id is a storage prefix, so it is validated where it enters

2026-10-02 — `POST /api/recordings/enqueue` took `jobId` from the form as-is, and that string becomes the S3 folder (`<id>/…`), the temp workspace (`path.join( os.tmpdir(), id )`, later `fs.rm`'d recursively) and — through the delete routes — an S3 listing prefix. The listing had no trailing slash, so deleting a job called `1` took every key starting with `1`, and a job called `""` (accepted: `"" ?? uuid()` is `""`) listed the whole bucket. Fixed at both ends: `src/lib/recordingInput.ts` (`isSafeJobId`, letters/digits/`-`/`_`, wider than UUID on purpose so a pre-UUID job stays usable; `isSafeObjectPath` for asset names and the sketch path, which legitimately contain `/`; `isSubmittableStatus` = draft | queued), and `deleteJobArtifacts` in `connections/s3.ts`, which lists `<id>/` only, paginates, batches by 1000 and refuses an unsafe id. Both DELETE routes share `src/lib/deleteRecordingJob.ts`. **How to apply**: a new route that turns an id or a name into a key prefix or a directory checks it with these helpers first; never list or delete by a bare prefix — always `<id>/`. Only the worker-written `resultUrl` may be deleted outside the folder; `thumbnails` is client-written at enqueue and must never drive a delete.

## `/api/s3` serves uploads from this origin, so it serves them sandboxed

2026-10-02 — `/api/s3/[...key]` streams any bucket object same-origin (it replaced a presigned redirect for WebKit `<video>`, see `recording.md`), with the `Content-Type` storage recorded; enqueue uploads client files with no explicit type, and MinIO fills one in from the extension (believed, not verified). An uploaded `.html` or `.svg` opened at that URL would have run as the site. Every response now carries `Content-Security-Policy: sandbox` and `X-Content-Type-Options: nosniff`. **How to apply**: keep both headers on any route that streams stored or user-supplied bytes from this origin; `sandbox` costs nothing for `<img>`, `<video>`, fonts or `fetch()` (a response's CSP only governs it when it is rendered as a document) — do not "fix" it with `default-src 'none'`, which would also stop a video opened directly in a tab.

## Request data never becomes a filesystem path through `path.join`

2026-10-02 — `/api/assets` built `path.join( os.tmpdir(), name )` from the query string, and `path.join` normalises `..` away: `?name=../../etc/passwd` returned `/etc/passwd` with a 200 (proved by `src/app/api/assets/__tests__/route.test.ts` against the old route), which in the container includes `/proc/self/environ` — the database URL and S3 keys. Nothing in the repo calls that route any more. **How to apply**: resolve untrusted segments with `src/utils/resolveInsideDirectory.ts`, which returns `null` when the result leaves the root (a `..`, an absolute segment, or the root itself), and answer 400 on `null`.
