# App Icon Instructions

You need to create two PNG icon files for your PWA:

## Required Files

1. **icon-192x192.png** - 192x192 pixels
2. **icon-512x512.png** - 512x512 pixels

## Quick Options

### Option 1: Use an Online Generator
Visit [RealFaviconGenerator](https://realfavicongenerator.net/) and upload your logo/image.
It will generate all required sizes automatically.

### Option 2: Use Favicon.io
Visit [Favicon.io](https://favicon.io/) to create icons from:
- Text (generate from letters)
- Image (upload your own)
- Emoji (use an emoji as icon)

### Option 3: Manual Creation
Use any image editor (Photoshop, GIMP, Figma, etc.):
1. Create a 512x512px canvas
2. Design your icon (keep it simple and recognizable)
3. Export as PNG at 512x512
4. Resize and export another version at 192x192

## Design Tips

- Use simple, bold designs that work at small sizes
- Ensure good contrast for visibility
- Consider both light and dark backgrounds
- Square aspect ratio works best
- PNG format with transparency if needed

## Temporary Solution

For testing, you can use the existing favicon or create simple colored squares:
- Use any 192x192 and 512x512 PNG images
- Name them correctly and place in the `public/` folder
- Replace with proper branding later
